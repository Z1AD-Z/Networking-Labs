# Networking Labs Roadmap

## Overview

This roadmap defines the learning path followed throughout the **Networking-Labs** repository.

Each laboratory introduces new networking concepts while reinforcing previously acquired skills. The objective is to progressively build practical experience equivalent to the knowledge required for the Cisco CCNA certification and beyond.

Progress is tracked by marking each completed lab.

# Learning Path

## Phase 1 — Networking Fundamentals

Objective:

Build a strong understanding of IPv4 networking and Cisco IOS configuration.

Labs

- Small Office Network
- Two LANs with Static Routing

Skills

- Ethernet
- IPv4 Addressing
- Cisco IOS
- Router Configuration
- Layer 2 Switching
- Static Routing
- Network Documentation
- Connectivity Verification

# Repository Standards

Every lab follows the same structure.

```
Lab/
│
├── README.md
├── *.pkt
│
├── configs/
├── screenshots/
└── notes/
```

Each project includes:

- Network topology
- IP addressing plan
- Cisco configurations
- Verification screenshots
- Technical observations
- Documentation

---

# Completion Criteria

A lab is considered complete only when all of the following have been documented.

- Network topology
- Device configurations
- Running configurations
- Routing or switching verification
- End device configuration
- Connectivity tests
- Technical observations
- Packet Tracer project
- Professional documentation
